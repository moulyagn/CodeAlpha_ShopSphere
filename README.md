# 🛍️ ShopSphere – AI-Powered Smart E-Commerce Platform

## The Idea

Shopping online often requires users to browse through hundreds of products before finding the right one. ShopSphere simplifies this experience by combining a premium e-commerce platform with AI-powered recommendations, intelligent search, and personalized shopping. Designed with a modern **Black & Gold luxury theme**, ShopSphere delivers a fast, secure, and seamless shopping experience.

# ✨ Features

- **🤖 AI Smart Search** – Search products naturally using queries like *"Best laptop under ₹60,000"* or *"Black sneakers for college"*.
- **🎯 Personalized Recommendations** – AI suggests products based on user preferences, browsing history, wishlist, and shopping activity.
- **🛍️ Modern Product Catalog** – Browse products by category, brand, ratings, and price.
- **🛒 Shopping Cart & Wishlist** – Add, remove, and manage products with real-time price calculations.
- **🔐 Secure Authentication** – User registration and login with JWT-based authentication.
- **📦 Order Management** – Place orders, view purchase history, and track orders.
- **⭐ Product Reviews & Ratings** – Share reviews and rate purchased products.
- **📱 Responsive Premium UI** – Fully responsive Black & Gold interface with smooth animations.

---

# 🛠️ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Flask + SQLAlchemy
- **Database:** PostgreSQL (Neon)
- **Authentication:** JWT Authentication
- **AI:** Groq API / OpenAI API
- **Deployment:** Netlify (Frontend), Render (Backend)

---

# 📖 Documentation

## How It Works

1. **Discover** – Browse products or search using AI-powered smart search.
2. **Shop** – Add products to your cart or wishlist.
3. **Checkout** – Complete secure purchases and manage orders.
4. **Personalize** – Receive AI-generated product recommendations based on shopping activity.

# 🔗 API Reference

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/auth/register` | POST | Register a new user |
| `/api/auth/login` | POST | Authenticate user |
| `/api/products` | GET | Retrieve all products |
| `/api/search` | GET | Smart product search |
| `/api/cart` | GET | View shopping cart |
| `/api/cart/add` | POST | Add product to cart |
| `/api/wishlist` | GET | View wishlist |
| `/api/orders` | GET | View order history |
